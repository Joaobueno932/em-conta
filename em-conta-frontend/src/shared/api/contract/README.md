# Contrato da API (cópia gerada)

Arquivos gerados por `npm run contract:update -- <origem>`. **Não edite à mão.**

- `openapi.json`: cópia do contrato publicado pelo `em-conta-backend` (`contract/openapi.json`).
- `schema.d.ts`: tipos TypeScript gerados com `openapi-typescript`.
- `contract-source.json`: produtor, versão da API e data da cópia.
